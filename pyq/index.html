    Auto-sync (phone ⇄ laptop)

    One private Gist is the shared store. Both devices read/write it automatically — no export, no import. Data is not sensitive; the token only has gist scope.
    not connected
    First-time setup (2 minutes, do it once per device)
    1. github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token.
    2. Name it pyq-loop, expiry 90 days, tick only the gist checkbox.
    3. Paste the token above → Connect / create gist. That creates a private gist and uploads current progress.
    4. On the other device: paste the same token → Connect. It finds the same gist and merges automatically.
